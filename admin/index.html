Connect

The console runs entirely in your browser and talks to GitHub directly. Your token and signing key never leave this device and are never committed to the repository.

Create it at GitHub → Settings → Developer settings → Fine-grained tokens. Scope it to this one repository. A classic token with repo also works but is far broader than needed.

Publish an interface update

Every file under web/ is hashed. Devices download only the files whose hash changed, verify the signature, then swap atomically. Journals are never touched.

Setting “Require at least this interface release” above a device's version shows the blocking Update required screen until it updates. Use it only for changes devices genuinely must take.

Build a new APK

Android code, permissions, the icon and the splash cannot be delivered over the air — they need a new APK. This dispatches the repository's build workflow, which compiles with the official SDK tools, signs with the release keystore held in repository secrets, and attaches the APK to a GitHub release.

Open Actions
A dispatched workflow is not a published release. Wait for the run to finish, then confirm the APK appears below before telling anyone to update.

Send a push alert

Alerts are delivered through a public ntfy topic — no Firebase project, no Google account, no user list. Apps listen while open and poll in the background roughly every 15 minutes, so delivery is best effort, not instant or guaranteed.

Anyone who knows the topic can read it. Never put personal information, journal content or credentials in an alert.

Edit interface files

Changes are committed to web/. They reach devices only after you sign and publish an interface release.

Release signing key

The APK contains one P-256 public key. A release is accepted only if it is signed by the matching private key. Import that private key here to sign releases from this browser.

No signing key loaded.
The private key is imported as non-extractable and, if you keep it, stored in this browser's IndexedDB. Anyone with access to this browser profile could sign releases. Keep an offline backup of the PEM; losing it means installed apps can never accept another update.

Convert an EC key

If your key begins with BEGIN EC PRIVATE KEY, convert it once:

openssl pkcs8 -topk8 -nocrypt -in update-private.pem -out update-private-pkcs8.pem
