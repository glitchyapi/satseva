Built to be trusted with something personal

Your journal is not a score, and it is not anybody's data. It stays on your phone.

Encrypted on the device

Entries are compressed, then encrypted with AES-256-GCM. The key is generated inside Android's hardware-backed Keystore and never leaves the phone.

Smaller than plain text

Compression happens before encryption, so the stored file is genuinely smaller than the raw JSON — the app shows you the real byte counts.

Offline first

Everything works with no connection. The only network request the app ever makes is to read its signed update feed.

Signed updates only

Every update feed is signed with a key baked into the app, and every file is hash-checked. A mirror can withhold an update but cannot forge one.

Downloads only what changed

Interface updates compare file hashes and fetch just the differences, then swap atomically. Your journal is never part of an update.

Bhandara banner studio

Make an invitation in three styles, in your language, and save it to your gallery or share it. No storage permission needed.

Installing

SatSeva is distributed here rather than through Play Store, so Android asks for one extra confirmation.

Download the APKTap the download button above and let the file finish. It should be a few hundred kilobytes — the app uses Android's built-in WebView instead of bundling a browser.
Open the downloaded fileUse your browser's download list or your Files app. If you open a GitHub page instead of the file, you will get an error — make sure it ends in .apk.
Allow this one installAndroid asks to allow installs from your browser or file manager. Allow it for that app, then go back and tap Install.
Open SatSevaIt starts empty. Nothing is uploaded, and there is no sign-up.
Already installed an older SatSeva build? Updating keeps your journal. If Android says “App not installed”, you almost certainly have a build signed with a different key — uninstall the old one first (export an encrypted backup from it if you want to keep the entries), then install this one.
The app never asks for access to your photos, contacts or location. Backups and banners go through Android's own file picker, which only ever shows the app the single file you choose.
